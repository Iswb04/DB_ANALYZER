IA → gera SQL
      ↓
Python (cursor.execute)
      ↓
Banco de Dados (MySQL)
      ↓
Retorna dados

* Pergunta em português → IA → SQL → Banco → Dados → IA → Resposta
* Você pergunta, IA traduz para SQL, código executa [cursor.execute(sql)], o banco retorna os dados e a IA explica o resultado

ollama pull nomic-embed-text - >RAG< (Retrieval-Augmented Generation)

modelo de Inteligência Artificial utilizado para transformar 
textos em números (vetores), permitindo que o sistema encontre 
informações com base no significado das palavras, e não apenas em 
palavras idênticas. 

-> pergunta ("qual vendeu mais?") 
-> transforma em vetor ([0.21, -0.48, 0.73, ...])
-> busca semântica (encontra descrições relevantes)
-> contexto (LLM+SQL para gerar consulta)

!!!!!!!!!!
nomic-embed-text: transforma texto em vetor.
ChromaDB: Busca descrições semelhantes
LLM: Interpreta a pergunta e gera a resposta.
